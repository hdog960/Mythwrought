## v0.10 Gate A foreground runtime and mesh pacing checkpoint — OPEN

It adds a one-request-at-a-time foreground render driver: hiding the page/pagehide/graphics loss stops animation; returning/pageshow can resume without multiple RAF loops, latching movement/look, or simulating away-time movement. A bounded nearest-first chunk-mesh cadence allows up to two rendering recovery frames after expensive uploads while preserving 5×5 loaded chunks and existing GPU buffers until their replacements succeed. Gate A device diagnostics now list mesh upload and deferred-frame counts. ## Features NOT implemented
The verified v0.09 prototype remains procedurally shaded voxel terrain, not approved premium handcrafted fantasy artwork. No authored village, deep cavern cities, NPCs, combat, classless progression, actual magic, water/lava simulation, blueprint editor, crafting, companions, wildlife, runic machinery, portals, or Death Echo yet. These remain locked design targets, not shipped systems.

## Open validation gates
1. **Gate A:** Actual iPhone Safari and installed landscape Home Screen visual, performance, control ergonomics, persistence across termination, error handling and save-integrity tests; not yet verified.
2. **Art gate:** Original material quality, characters, cave art and animation require owner acceptance, not a self-declared pass.
3. **Save gate:** Current v0.01 uses localStorage as temporary proof of concept. IndexedDB, versioned migration and backup/recovery safeguards remain needed.
4. **Scale gate:** Real iPhone chunk streaming, caves, world saves and simulation load still must be profiled.

## Reporting rule
Never label planned roadmap releases complete without independently tested implementation evidence and user-required gates. No guarantee the page works on every iPhone solely because headless Chromium and HTTP fetch pass.
