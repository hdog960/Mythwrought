# Original reconciliation readiness — detached safety gate

The original `PopulationManager.#reconcile` executes on every due 0.5s tick even when no regions are available. It can wake nearby dormant mobs, sleep far idle mobs, and maintain a private away ledger for six-second removal. Pure source proposals do not own that ledger and must not claim source-equivalent spawning while this work remains outstanding. The new read-only inspector checks the original 18-block active radius, real original `MobEngine.all()`, authoritative 3D residency and voxel revision and returns a frozen list of required actions. It deliberately flags every far mob, including protected creatures, because the away state cannot be reconstructed. It never changes an engine, world, PWA or save. Native Node and original M7 tests remain required; this is not a replacement for live reconciliation.
