## Source engineering — no new vertex format
- The 9×Float32 layout (XYZ, RGB, UV, art material) in original `src/voxel.mjs` stays exactly **36 bytes/vertex**. This experiment only reuses the existing *fractional part of the ninth float* for the already exposed `vPack2Alpha=fract(aMat)` interpolation channel. The integer art-material ID stays **40** for natural Desert terrain. No block ID, geometry, UV, lightmap, texture, index, draw call, transparent pass, saved edit, baseline/cave world plan, or GPU attribute is added.
- Existing three-block world-coordinate RGB blend is unchanged: the same proven weight (0 through 0.64) now also packs `40+weight` on **only authentic original natural low-weight Desert hardpan top-cap vertices** close to genuinely original unedited Mountain scree 401. Non-eligible and edited surfaces continue using exactly 40.0. All other material tags and special water/particle channels are unchanged.
- New pure module `src/manual-biomes/desert-seam-shader.mjs` matches exactly one known original `if(vMat==40)` branch, failing closed on missing/multiple anchors. `src/main.mjs` uses it only after the existing shader variable `vPack2Alpha` is declared. Only when `vMat==40 && vPack2Alpha>0.001` does the high-art-quality fragment path interpolate original sand/grit/sweep shading toward the original material42 rock-grit pattern, using world-space UV and **one extra deterministic hash only at tagged seam fragments**. Untagged 40.0 runs original math, other biomes/material42 and water20/particles23 take exactly the existing paths. Low-art-quality mode keeps the original fast path and inherited RGB feather.
- **Careful distinction:** exact fractional ninth-float values *do* change on the eligible 40.x mesh vertices. Integer material ID does **not** change. The previous "all nine floats equal" contract from RGB-only research is therefore superseded by a stronger selective contract: XYZ/RGB/UV are byte-identical and floor(material) is identical; only the tagged natural 40.x fractional field is allowed to vary. No new GPU memory bytes.
