# N1 channel topology → N3 allocation adapter (source-only)
Contract: `resonance-network36-graph-allocation-v1`. Entry point: `allocateFromChannelGraph`.
Inputs: externally authenticated loaded channel and endpoint descriptors, integer tick, generator availability, device demand/priority, storage capacity/charge/rates. Calls the exact existing N1 channel graph and N3 scoped allocator without modifying either. Membership is derived from adjacent channel geometry, never accepted from caller-supplied network labels. Missing endpoint IDs fail; ambiguous/disconnected endpoints receive no power and are reported. On split, storage charge remains attached to the storage endpoint; it cannot migrate to another component. On rejoin, a device can resume automatically.
Safety: the module does not authenticate observations, generator fuel reservations, player edits, source identity, chunk loading or save authority. An external trusted adapter must validate these before calling. This candidate is not an inventory receipt or authorization to deliver power. No persistent state, production registration, world edits, renderer, block IDs, wireless, settlements or damage. Full graph rebuild remains bounded but not incremental; do not run every frame. No iPhone/WebGL2/offline acceptance claimed.
Focused test command: `node --test tests/resonance-network36-graph-allocation.mjs`. The test cases cover split, join, disconnected and ambiguous members, identity validation and storage separation. Exact committed-head execution is required before accepting this candidate.
