# N3 scoped allocation candidate (source-only)
Contract `resonance-network36-scoped-allocation-v1`. `allocateScopedResonance` accepts an explicit, externally authenticated array of network IDs and arrays of generator availability, devices, and storage records, each with a `network` ID. It delegates to the isolated N3 single-network allocator and forbids power transfer across distinct network IDs. Input identity is unique across all members; aggregate sums are safe integers. Output is deterministic by network ID and includes per-network status and aggregate accounting. No graph construction or connectivity authentication is implied: caller must derive network IDs from authoritative loaded channel/wireless topology and reject stale or untrusted membership. No generation/fuel authority, inventory withdrawals, saves, world edits, damage, new block IDs, rendering, or production registration. Network splitting is represented by caller-supplied membership; battery charge cannot migrate between components. Explicit opt-in only.
