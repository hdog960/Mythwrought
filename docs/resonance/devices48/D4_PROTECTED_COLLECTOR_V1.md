# D4 protected collector preview v1
Source-only, opt-in, non-production collector intent. Accepts up to 64 observations and deterministic lexical ordering. Only fixture-owned opt-in drops are eligible; protected edits, player ownership, non-drop sources and cross-world objects are rejected. Capacity and proposed power are bounded; no real :36 delivery receipt is authenticated. Every result explicitly has `canActuate:false`. Does not touch voxel edits, inventory, saves, collision or renderer. No production registration. Run focused tests: `node --test tests/resonance-devices48-protected-collector-v1.test.mjs`. Future integration requires authoritative power, inventory and owner consent.
