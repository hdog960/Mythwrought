# :48 D1 momentary button edge v1

Source-only, opt-in, unregistered. The pure deterministic `advanceButtonEdge(previous,input)` observes a physical button's rising/falling edges and ignores held-button repeats. Power is an untrusted observed boolean, **not** authenticated :36 delivery. `observedPress` is a preview event only, never a device actuation command. Outputs always set `activationAuthorized:false`, `authoritativeDelivery:false`, and `productionBound:false`. No block IDs, inventory, physics, renderer, saves, settlement or production registration. Requires contiguous integer ticks and stable world/device identity. Later :36 integration must authenticate delivered energy before actuation; a game owner must bind actual input and assets. No real device or screenshot is claimed.
