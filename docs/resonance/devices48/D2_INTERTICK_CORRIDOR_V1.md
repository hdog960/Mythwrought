# D2 Intertick corridor preflight v1
Source-only optional preview. Reads 2–16 consecutive, same-world, same-device, non-production frames and calls the existing conservative whole-corridor preflight at each tick. Any observed blocker remains reported even if a later frame clears. Stable sorted blocker IDs and immutable per-tick reports. Refuses gaps, world/device changes, invalid tick ranges, forged delivery and production binding.
This is NOT a continuous real-time physics sweep between samples; an actor may enter between ticks. It never permits actuation, modifies voxels, registers blocks, grants power, or changes saves. Real-world movement requires game-owned swept collision, edit protection, and authoritative :36 delivered-power receipts. The source-only clear result must never be interpreted as permission to move.
Focused tests: 12 local Node 22-compatible tests passed against a locally reconstructed copy of the previously fetched corridor module; committed-head native execution and WebGL2 remain pending.
