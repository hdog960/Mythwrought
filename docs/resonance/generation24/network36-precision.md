# G4 conservative integer handoff precision repair
The optional network36 integer candidate adapter uses conservative micro-unit quantization (floor, never nearest). Sub-micro-unit energy is discarded per tick, not stored or claimed; the maximum discarded quantity is strictly less than one micro-unit per tick for valid positive input. This avoids rounding-driven energy creation but is **not exact conservation** for tiny rates. A future higher-precision contract may be required for very-low-output sources. The existing checkpoint signature stays v1 because its fields and meaning are unchanged; the result now advertises quantization policy. External checkpoints are unauthenticated candidate data, never fuel receipts or network-delivery authorization. No production registration. Run node --test tests/resonance-generation24-network36-integer.mjs tests/resonance-generation24-network36-precision.mjs. The standalone precision test was executed with a minimal CONTRACT stub; full-repository tests, actual :36 compatibility and browser acceptance remain pending.
