## Duplicate/mirror prevention

The source native suite compares the new candidates against the entire existing
**45**-design pool (including all original 15 watchtowers and 30 first-variant
lumberyards/mills). Exact type/palette-independent geometry fingerprints all
differ. A **D4 geometry audit** maps each source foundation silhouette to a
normalized 24×24 grid, then computes Jaccard similarity across all eight
reflections/quarter-turn rotations. The new designs must be **under 0.89**
similarity with *every* other design, including each other, failing CI if
they are only mirrored, rotated, scaled, or near-duplicate footprints.
Source preflight peak was ~0.87838, below this gate. This is a meaningful
screening heuristic, not a guarantee of unique visual quality.
