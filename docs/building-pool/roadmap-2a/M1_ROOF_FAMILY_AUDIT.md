# 2A M1 producer-backed real roofing + glazing diagnostic

`m1-roof-family-audit.mjs` reads **all actually authored 2A cells** and resolves unambiguous roof/window physical descriptors against the real integrated `src/builder-assets/manual-five-pack.mjs` producer. It records source Pack 1–5 numeric variations, visible/selection/collision boxes, true occupied/support offsets and facade yaw, plus missing physical window opening data. Ambiguous Pack 5 roof variants are **not guessed**; unresolved dependencies are preserved. Every roof cell receives an explicit conceptual vertical-bearing check, so long-span flat plates and missing supports are reported rather than misleadingly called production-safe. Six recent regional raised roof assemblies have source-stacked support (verified separately), but final shape/collision/mount/structural weather/transparent-glass and schema-1 save approval is not asserted.

This is a read-only producer descriptor audit, not actual physical-family WebGL2 mesh rendering. Production physical block placement, load ratings and external terrain supports require the central integrator. The native tests exercise real producer descriptors and deliberately remove a physical supporting roof voxel to prove an unsupported cell is detected. **Zero creator-approved and zero integrated.**
