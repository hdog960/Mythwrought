# Builder 2A producer-backed physical-family inspection (read-only M1)
`src/building-pool/roadmap-2a/m1-physical-audit.mjs` reads the **real merged** `src/builder-assets/manual-five-pack.mjs` API (96 distinct manual family symbols, 106 physical candidate variants). It examines all 26 actually authored 2A blueprints, their material refs, all source window facade-facing cells and fixtures with explicit Pack 5 variants, including the original 15 General Stores. It calls the **actual** `resolveManualFivePackAsset` descriptor API for eligible windows and fixtures, records orientation, selection/collision box counts, footprint offsets and potential overlaps with already occupied conceptual cells; unresolved or ambiguous cases are explicitly recorded, not filled with guessed cubes.
**Important:** a producer-backed physical descriptor is not approval that all construction cells coexist with their true multi-cell footprint, supports, shape rotation or saved state. Physical glass/frame fit and transparency, full roofing support, standalone mounts and any unregistered biome130 dependencies require central ABI review. Live placement and schema-1 saves remain unchanged. The diagnostic WebGL2 renderer remains **cube proxy**, not physical-family mesh.
Run `node --test tests/building-pool/roadmap-2a/*.test.mjs`, including the new producer-backed tests. The tests assert all manual family refs resolve, inspect selected true physical variants and stay dry-run, but explicitly do NOT require zero unresolved 130 assets, zero footprint overlaps or real world readiness.
