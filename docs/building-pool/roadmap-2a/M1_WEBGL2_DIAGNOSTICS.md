# 2A M1 source-coordinate WebGL2 browser diagnostic
This owner-local HTML imports all 26 actual committed 2A source blueprints (15 inherited stores, five first specialists, six additional originals). It renders their exact integer occupied voxel cell coordinates using **real WebGL2 instanced cube proxies**. It has exterior and roof/front cutaway views and an explicit watermark. The candidate renderer cannot substitute for the actual physical shaped block-family pipeline; transparency, rotated variants, collision, support and save ABI remain outstanding.
Run `python3 tests/building-pool/roadmap-2a/m1-gallery-browser.py` after checking out this PR with installed Python Playwright and Chromium. The capture script checks WebGL2 context, GL errors and screenshot signatures across all 26 source designs, exterior and cutaway, at 667×375, 844×390 and 932×430 (156 frames). Screenshots are local `artifacts/roadmap-2a-cube-proxy/`, outside the source PR.
**No claim of execution or screenshot inspection is made merely by committing this harness.** CI's generic production-game smoke/layout does NOT run this candidate harness. Browser tests and creator/art/physical iPhone approval are independent gates. Draft only, no merge, deploy, engine or save changes.
