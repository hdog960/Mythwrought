## What the new code measures, and what it does not

`d41-finite-route-failure-certificate.mjs` implements independent source/standing-body/socket AABB screening with the exact D40 constraints: radius four, original Y3–Y6, 0.08 half-width, one-axis six-connected segments, intact original Y0–Y7 founded wall, and original D36 socket **conservative axis-aligned bounds**. It traces five separate necessary stages:

1. **Front and rear route entry.** Classifies available Y5 and Y6 front and rear centers, preserving independently attributed source-solid, original WALK standing-body and socket-AABB obstruction counts. A front or rear blocked root is classified before testing remote route closure.
2. **Center-only graph.** Builds connected components of genuinely vacant source centers, measures whether any front can reach an actual rear center *without yet requiring prism edges*. A disconnected graph rules out D40's candidate class regardless of fastener strength.
3. **Full finite-thickness edge graph.** Checks every explored adjacent pair as a bounded 3-D 0.16-unit-thick square prism, includes turns as union of full prisms, counts actual source-cell/standing-body/socket intersection vetoes, records swept front-to-rear connectivity and visited volume. Center-only reachability **does not** certify physical edge clearance.
4. **Projected winding closure.** Only when the rear is swept-reachable, tracks signed angular branch-cut crossings in the bounded state graph, requires full ±1 projected winding and return to original front. Front-to-rear alone is not an enclosing loop. An enclosing loop is not a fastened, rated load path.
5. **Cross-check against the actual D40 helper.** The new source-native audit independently rebuilds each of 128 original rooted D35-cleared ID61 diagonal/D36 socket/D37 normalized-positive-tension chains, compares the D41 complete-loop result, front and rear elevations, admissible center count and each center blocker count with the existing untouched D40 helper, and fails on disagreement.

The result is classified per genuine original wall root as: `front-and-rear-source-entries-blocked`, `front-source-entry-blocked`, `rear-source-entry-blocked`, `center-graph-disconnected`, `swept-segment-graph-disconnected`, `winding-or-closure-unavailable`, or `complete-bounded-route`. These are **exclusive classes ordered by earliest necessary failure**, not global claims about physical impossibility. Source-solid, standing-body and socket veto counts are **overlapping observation counts**, not unique blocked original voxels. Multiple observed graph front components do not establish actual mechanical capture. A source-preserving connector with genuinely different topology, route envelope, approved source materials or attachment might behave differently.

The D36 socket AABB is intentionally conservative and may overreject compared with a future true convex collision test. D41 does not claim to implement a full original-world runtime collider for unregistered composite straps; no actual joint/wall fastener, tensile pullout, cyclic fatigue, roof gravity/uplift, foundation strength, original UV endcaps or production player/NPC/WebGL2/PWA acceptance exists. A legitimate candidate still requires independent creator/owner authorization and proof of physical mechanical retention with authenticated measured strength. A face-only coupon, vacant cell, certificate or fabricated input rating cannot satisfy that burden.
