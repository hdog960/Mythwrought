# Builder 1A — source Pack1–5 visibleBox WebGL2 preview (separate from cubes)

A new read-only viewer mode builds genuine geometrical AABBs from actual five-pack producer `resolveManualFivePackAsset`. It does NOT substitute a 1×1×1 bounding cube for Pack assets. The only full-cube fallback is for documented `live:` game-original blocks. Every Pack face is emitted from the exact source `visibleBoxes` with candidate orientation and explicit Pack5 variant when supplied; unspecified Pack5 variants use the current first producer-catalog variant and are recorded as *provisional*, not creator-selected.

For each of five small newly authored houses (one per biome), the CI browser captures exterior/cutaway at 667×375, 844×390, 932×430 = **30 target genuine source-family AABB WebGL2 images**. Separate old 41-building cube view target = 246. Both have explicit, distinct renderer metadata.

**What this IS:** physical geometry AABB silhouette sourced from Pack1/2/3/4/5 manufacturer/integrator code, actual 1A voxel coordinate placements, actual WebGL2 vertex shader, framebuffer validation, native Node source inspector, provisional role-based colors.

**What this IS NOT:** artistic mesh textures, integrated VoxelWorld material renderer, author-approved state for hinged-open Pack2 door leaves, verified save schema-1 orientation and variants, correct roof weather/load stress, pane transparency, collision-through doors, iPhone hardware, final visual/creator acceptance. The audit does not write to world or alter shared owned paths. Variant defaults and door swept volumes remain open release gates.

**Status at commit:** CI required; never claim screenshots passed until exact-head artifacts confirm.
