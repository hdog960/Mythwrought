## S3 genuinely new work: deterministic site selection and physical rejection
`snowS3SitesForChunk` uses sparse 8-cell global sites and a 3-voxel cross-chunk margin; neighboring 16-cell chunk evaluations see identical overlapping candidate site keys. The altitude-guided selection chooses the four existing **detached** physical tree variants (compact fir, layered spruce, highland pine, windswept alpine), never writes to the world, and does not depend on chunk evaluation order. `proposeSnowS3PhysicalSite` requires caller-supplied original M7 interior weight, real snow cap (272,276,279), non-AIR support, unedited/unprotected footprint, currently AIR tree volume, authorized physical voxel IDs (WOOD 4, needles 406/407), complete trunk and bounded 16–119 voxel proposal. Fail closed on incomplete evidence. Existing tree factory `proposedSnowTree` remains separate, and actual original-world wiring is an acceptance gate.
