# Movement12 trace continuity gate
Source-only diagnostic; no production registration. `auditTraceContinuity` rejects missing or nonfinite positions, nonmonotonic timestamps, gaps, and implausibly large position changes. Ten deterministic Node tests: `node --test tests/movement12-trace-continuity.test.mjs`. Defaults are conservative diagnostic ceilings, not measured Gate A speed limits. A pass does not prove collision-free travel between samples, frame-rate parity, physical iPhone controls, WebGL2, or saved-world safety. Integrate with genuine `recordRealStepTrace` evidence only after tuning thresholds against actual movement speeds. Never use this gate to change production physics or touch rails.
