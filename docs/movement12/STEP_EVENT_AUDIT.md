# :12 step-event audit v1
This opt-in source-only module examines actual stepPlayer recorder frame events and feet positions, reporting unexpected vertical discontinuities, steps without recorded rise, wall hits and descending frames. It is not a new physics engine, a continuous collision proof, or a production hook. The caller must supply authentic recorder data and calibrate maxRise/maxDrop to observed cadence and terrain. Run `node --test tests/movement12-step-event-audit.test.mjs`. Synthetic unit fixtures validate the audit contract only; real-game shaped-terrain, Creative flight, touch rails, Chromium/WebGL2, offline and save acceptance remain separate. Do not merge or deploy without creator authorization.
