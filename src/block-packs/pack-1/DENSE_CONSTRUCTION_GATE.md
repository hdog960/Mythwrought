# Pack 1 — source-level dense-building and save-contract stress (isolated)

**Candidate-only.** These are preparatory requirements and a reproducible offline stress harness, NOT live-game deployment or verified physical-iPhone performance.

`construction-stress.mjs` is a pure no-world-writes implementation of the proposed five-pack construction adapter contract. It composes real Pack 1 source definitions from `builder-handoff.mjs` and `webgl2-candidates.mjs`. It leaves schema-1's `{schema,seed,edits}` structure untouched and records *disjoint* `pack1State` arrays: `turns` (compatible in shape with current main's orientation sidecar), `variants` for upper stone slab/stair (not handled by orientation alone), and `mounts` for a validated vertical supporting face.

The adapter explicitly rejects ambiguous `pack1:NNN` materials, duplicate occupied cells, missing wall supports, stale or duplicate state entries, invalid orientations, and metadata loss. Legacy IDs 0–8 and other packs' unknown positive numeric IDs are retained untouched; no other-packs' geometry or save state is inferred. Removing a support under a mounted vine fails closed and leaves the original snapshot untouched. Future final integration should define state lifecycle, atomic rollback, and safe metadata storage in the real engine.

`tests/block-packs/pack-1/construction-stress.test.mjs` checks all four orientations for all 30 physical IDs, 120 shape entries including 8 upper stone variants and 8 mounted vine states, disjoint schema-1 compatibility, corruption/failure guards, and a deterministic 25-chunk horizontal 80×80 sample (6400 physically authored candidate cells). The sample computes conservative individual source-surface triangles *before neighboring chunk-face culling*, with bounded material/shape cache and serialized metadata. This is NOT a frame-time benchmark or proof of phone thermal/60 FPS behavior; production 25/34/27 chunk budgets and physical iPhone art/control approval remain integration-only gates.

Standalone source tests must execute the expanded native suite on the exact current candidate head, then independently run the original 360 WebGL2 candidate renders and authenticate 90 PNGs. Do not mark final readiness from this source alone.

A deterministic, noncryptographic checksum of the exact schema-1 edit rows plus orientation, upper-variant and mounting records detects accidental partial or full metadata loss on restore. A missing or mismatched checksum **fails closed** rather than silently reverting a rotated stair or mounted vine to default geometry. This is a Pack 1 source-level compatibility demonstration, not a production security seal or permission to alter the real save format. For production multi-pack integration the shared save owner must decide and validate stronger persistence/rollback semantics.
