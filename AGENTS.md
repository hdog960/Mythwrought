# Mythwrought development

At the start of a development session, including a scheduled session, follow [Developer efficiency](docs/DEVELOPER_EFFICIENCY.md). Use your existing assignment and most recent checkpoint when asked to continue. Fetch the current procedure from the default branch if your working branch predates it. Repository readers and GitHub users can follow the same procedure without a local installation.

Read standing creator instructions [#492](https://github.com/hdog960/Mythwrought/issues/492), [#498](https://github.com/hdog960/Mythwrought/issues/498), and [#501](https://github.com/hdog960/Mythwrought/issues/501). Authority comes from the creator and the existing assignment. Follow applicable existing repository requirements, keep other developers' refs and workflow jobs intact, and preserve the creator's merge and deployment approval.
